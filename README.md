# Task_2
# Проект API Автотесты для сервиса Stellar Burgers
содержит автоматизированные тесты для проверки API ключевых функций сервиса: управление пользователями и заказами.

## Структура проекта:
* `allure-report/` — отчеты allure
* `tests/` — тестовые модули
* `src/` — тестовые данные, конфигурация
* `.gitignore` — список игнорируемых файлов
* `README.md` — описание проекта

## Написаны тесты на функциональность:
* **«Создание пользователя»** — модуль `test_signup_user.py`:
    * можно создать уникального пользователя;
    * нельзя создать пользователя, который уже зарегистрирован;
    * нельзя создать пользователя, если не заполнено одно из обязательных полей.

* **«Логин пользователя»** — модуль `test_login_user.py`:
    * пользователь может авторизоваться (передача всех обязательных полей);
    * система вернёт ошибку, если указать неверный логин или пароль.

* **«Изменение данных пользователя»** — модуль `test_update_user.py`:
    * изменение данных с авторизацией (любое поле можно изменить);
    * система вернёт ошибку при изменении данных без авторизации.

* **«Создание заказа»** — модуль `test_create_order.py`:
    * создание заказа с авторизацией;
    * система вернёт ошибку при создании заказа без ингредиентов;
    * система вернёт ошибку при создании заказа с неверным хешем ингредиентов;
    * система вернёт ошибку при создании заказа  неавторизованным пользователем.

* **«Получение заказов конкретного пользователя»** — модуль `test_list_orders.py`:
    * получение списка заказов авторизованным пользователем;
    * система вернёт ошибку при получении заказов неавторизованным пользователем.
